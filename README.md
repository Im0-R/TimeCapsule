## Overview

TimeCapsule is a Creajeux school project created over two months by five programmers and three artists. The game explores memory through a central mechanic: switching between the childhood and adult versions of the same environment.

Objects, clues and emotional context change with time. Players use those differences to solve interconnected puzzles and understand the story hidden inside the space.

## Core Experience

- Switch between two time periods to reveal different versions of the environment.
- Collect and inspect objects through an inventory system.
- Combine clues across timelines to solve layered puzzles.
- Use environmental audio and music to support the narrative.
- Reinforce the time-shift mechanic through custom Shader Graph effects.

## Production Focus

TimeCapsule was an exercise in making several disciplines serve one clear mechanic. Puzzle state, inventory data, art swaps, sound and shaders all needed to remain synchronized when the player changed time period.

The project strengthened my experience with:

- State-driven puzzle design
- Cross-scene and cross-system integration
- Designer-friendly gameplay tools
- Shader Graph and visual feedback
- Audio implementation in Unity
- Team production over a fixed deadline
